# Vector and Set

Учебный Python-проект по основам объектно-ориентированного программирования.

Проект реализует две математические сущности:

- трёхмерный вектор;
- пользовательское множество.

Основная цель проекта — реализовать предметную логику внутри независимых
доменных классов и отделить её от пользовательского интерфейса.

## Возможности

### Vector

Класс трёхмерного вектора поддерживает:

- получение координат;
- вычисление длины;
- сложение и вычитание векторов;
- векторное произведение;
- умножение вектора на число;
- деление вектора на число;
- вычисление косинуса угла между двумя векторами;
- сравнение векторов по длине;
- сравнение объектов на равенство;
- преобразование объекта в текстовое представление и восстановление из текста.

### Set

Пользовательский класс множества поддерживает:

- вложенные множества;
- проверку множества на пустоту;
- добавление и удаление элементов;
- определение мощности;
- проверку принадлежности элемента;
- объединение;
- пересечение;
- разность;
- построение множества всех подмножеств;
- создание множества из текстового представления.

## Архитектура

Проект разделён на несколько частей:

- `domain` — предметные сущности и правила;
- `presentation/cli` — консольный пользовательский интерфейс;
- `tests` — автоматические тесты;
- `docs` — документация проекта.

Доменный слой не зависит от пользовательского интерфейса.
